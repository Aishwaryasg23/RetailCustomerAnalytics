# Retail Customer Analytics | SQL Server, Python & Power BI

## Project Overview

This project analyzes retail transaction data to understand customer purchasing behavior, identify valuable customer segments, and monitor customer churn.

The project follows an end-to-end analytics workflow using SQL Server for data integration and cleaning, Python for customer-level analysis and RFM segmentation, and Power BI for interactive dashboards and business insights.

## Business Objectives

- Analyze customer purchasing behavior and revenue trends.
- Identify high-value, loyal, and at-risk customers.
- Understand customer churn across segments and time periods.
- Provide actionable recommendations to improve customer retention and revenue.

## Project Workflow

### 1. SQL Server – Data Integration & Data Cleaning

The SQL component focuses on integrating two years of retail transaction data into a consolidated dataset and preparing it for analysis.

**Key Activities**

- Created the `EcommerceCustomerAnalytics` database.
- Combined the 2009–2010 and 2010–2011 datasets using `UNION ALL`.
- Standardized invoice dates and price data types using `TRY_CONVERT()` and `COALESCE()`.
- Validated the combined dataset by comparing source and destination row counts.
- Performed data quality checks to identify missing customer IDs, descriptions, invalid quantities, and null date or price values.
- Identified exact duplicate transactions using `GROUP BY` and `HAVING`.
- Implemented deduplication using a CTE and `ROW_NUMBER()` to retain one record from each exact duplicate group.
- Created a cleaned dataset named `CleanedRetailData` for downstream analysis.

**SQL Concepts Used:** `UNION ALL`, `TRY_CONVERT()`, `COALESCE()`, `CASE`, `COUNT()`, `GROUP BY`, `HAVING`, CTEs, `ROW_NUMBER()`, and `SELECT INTO`.

### 2. Python – RFM Analysis & Customer Segmentation

The Python component uses the cleaned SQL Server dataset to analyze customer behavior, calculate RFM metrics, and classify customers into meaningful segments.

**Key Activities**

- Connected Python to SQL Server using SQLAlchemy and pyodbc.
- Retrieved the cleaned transaction data using Pandas.
- Inspected the dataset structure, data types, and missing values.
- Filtered transactions to retain valid customer IDs and positive quantities for RFM analysis.
- Converted invoice dates into datetime format and created an invoice month column.
- Calculated transaction revenue using Quantity × Price.

**RFM Analysis**

Calculated three customer-level metrics:

- **Recency:** Number of days since the customer's most recent purchase, using December 10, 2011, as the reference date.
- **Frequency:** Number of unique invoices generated by each customer.
- **Monetary:** Total purchase value generated by each customer.

**Customer Segmentation**

- Applied quintile-based scoring using `pd.qcut()` to assign RFM scores from 1 to 5.
- Used conditional logic to classify customers into Champions, Loyal, At Risk, New, and Needs Attention.
- Created an `IsChurned` indicator to flag customers whose last purchase was more than 90 days before the reference date.
- Merged customer-level RFM metrics and segment classifications with transaction-level data.
- Exported the final enriched dataset to CSV and SQL Server for Power BI reporting.

**Python Libraries & Concepts:** Pandas, NumPy, SQLAlchemy, pyodbc, data filtering, aggregation, feature engineering, RFM scoring, customer segmentation, and database integration.

### 3. Power BI – Interactive Business Intelligence Dashboards

The Power BI component transforms the cleaned and enriched data into interactive dashboards for monitoring customer performance, revenue, and churn.

The dashboard provides a high-level view of customer and business performance.

**Key Metrics**

**Analysis**
- Customer distribution across segments.
- Customer retention by segment.
- Customer counts by month, quarter, and year.
- Customer churn trends over time.

#### RFM Analysis Dashboard

The dashboard provides a deeper understanding of customer value and behavior.

**Key Metrics**
- Total Customers
- Total Revenue
- Average Recency Score
- Average Frequency Score
- Average Monetary Score

**Analysis**
- Customer segment performance by country.
- Average customer value across countries.
- Monthly, quarterly, and yearly churn trends.
- Customer purchasing behavior using RFM metrics.

## Key Business Insights

- The Business Overview dashboard reports 5,881 customers and approximately $17.37 million in revenue.
- Needs Attention is the largest customer segment, with 1,667 customers.
- Needs Attention and At Risk together represent 3,007 customers, highlighting an opportunity for targeted retention campaigns.
- The RFM dashboard reports 5,726 customers and approximately $16.17 million in revenue.
- The United Kingdom contributes approximately 89% of the revenue reported in the RFM dashboard.
- Quarterly churn declines from 48.02% in Q1 to 34.14% in Q4.

## Business Recommendations

1. Prioritize retention campaigns for customers in the Needs Attention and At Risk segments.
2. Investigate churn patterns by month and quarter to identify potential seasonal or behavioral drivers.
3. Develop personalized engagement strategies for Loyal and Champions customers.
4. Monitor revenue concentration in the United Kingdom while exploring growth opportunities in other markets.
5. Validate customer counts, revenue calculations, and churn definitions across dashboards before using the results for business decisions.
